
# Skybrisk Internship - Month 1, Week 1
## Python Basics and Data Processing

### Project Overview

This project was completed as part of the Skybrisk internship
Month 1, Week 1 task.

The objective is to practice Python programming fundamentals
and implement basic scripts for calculations and data processing.

### Objectives

- Understand Python variables and data types.
- Practice input and output.
- Use arithmetic operators.
- Implement conditional statements.
- Perform basic data processing using lists.
- Calculate average temperature readings.

### Technologies Used

- Python 3
- Visual Studio Code

### Project Structure

```text
Week_1_Python_Basics/
├── calculator.py
├── temperature_converter.py
├── average_temperature.py
├── Python_Basics_Notes.docx
└── README.md
```

### Programs Included

#### 1. Calculator

File: `calculator.py`

Performs addition, subtraction, multiplication, and division
based on the user's selected operation.

Concepts: variables, input, type conversion, operators,
conditional statements, and error handling.

#### 2. Temperature Converter

File: `temperature_converter.py`

Converts temperatures between Celsius and Fahrenheit.

Concepts: input/output, arithmetic formulas, and conditions.

#### 3. Average Temperature Calculator

File: `average_temperature.py`

Calculates the average of temperature readings stored in a list.

Concepts: lists, `sum()`, `len()`, arithmetic, and conditions.

### Installation and Execution

1. Install Python 3.
2. Open this folder in Visual Studio Code.
3. Open Terminal > New Terminal.
4. Run the programs individually.

```bash
python calculator.py
python temperature_converter.py
python average_temperature.py
```

On Windows, you can use `py` instead of `python` if needed.
