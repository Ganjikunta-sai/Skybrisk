# Month 1 - Week 2: Python Data Structures and Data Cleaning

## Topics
- Lists, tuples, dictionaries, and sets
- Functions, lambda expressions, recursion, and list comprehensions
- Basic data cleaning and summary statistics

## Run
```bash
python week2_data_cleaning.py
```

## What to observe
The script skips missing, blank, and invalid temperature values, then prints the count, average, minimum, and maximum. It also demonstrates a list comprehension and dictionary.
