# Month 1 - Week 4: Data Visualization

## Topics
- Matplotlib and Seaborn
- Bar plots, scatter plots, and heatmaps
- Interpreting charts and correlations

## Setup
```bash
python -m pip install -r requirements.txt
```

## Run
```bash
python week4_visualization.py
```

The script displays charts and saves three PNG images in the working directory. Correlation shows association and does not by itself prove causation.
