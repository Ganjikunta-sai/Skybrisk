# Month 1 - Week 3: NumPy and Pandas

## Topics
- NumPy arrays and numerical operations
- Broadcasting and aggregation
- Pandas DataFrames, indexing/filtering, and groupby

## Setup
```bash
python -m pip install -r requirements.txt
```

## Run
```bash
python week3_numpy_pandas.py
```

The script creates a small temperature dataset, filters Hyderabad records, and calculates average temperature by city.
